# DAS7002 Big Data Technologies – PRAC 1

Cardiff Met ID: st20357375
ICBT ID: CL/MCSDS/CMU/10/03

## Project Overview

This repository contains the PySpark implementation developed for the
DAS7002 Big Data Technologies PRAC 1 assessment.

The project analyses the Chicago Crime dataset using distributed data
engineering, exploratory analysis, K-Means clustering and Random Forest
classification.

## Main Tasks

1. Distributed ETL and data quality analysis
2. Temporal, spatial, socio-economic and weather analysis
3. K-Means spatial-temporal clustering
4. Random Forest arrest prediction

## Technologies

- Python
- PySpark
- Apache Spark
- Spark SQL
- Spark MLlib
- Google Colab
- Pandas
- Matplotlib

## Main Data Sources

- Chicago Crimes – 2001 to Present
- Chicago Selected Socioeconomic Indicators
- Open-Meteo Historical Weather / ERA5

## Notebook

`DAS7002_PRAC1_st20357375.ipynb`
